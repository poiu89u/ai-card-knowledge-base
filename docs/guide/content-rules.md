# 内容规范

每张知识卡片都按同一套字段维护，避免后续扩展时变成散乱笔记。

## 卡片字段

| 字段 | 用途 |
| --- | --- |
| 名词 | 知识点的标准名称，优先使用官方叫法 |
| 分类 | 固定归入初始类目，新增分类前先复核目录 |
| 标准定义 | 贴近官方文档、官方指南或权威教材表述 |
| 小白解释 | 用生活化语言解释，但不改变原理 |
| 官方要点 | 背面展示官方文档能直接支持的核心事实 |
| 小白记法 | 一句话帮助外行快速记住 |
| 别误会 | 标注常见误区、边界和风险 |
| 使用场景 | 说明它能解决什么实际问题 |
| 标签 | 支持快速筛选和后续检索 |
| 版本 | 标注模型、框架或工具版本 |
| 更新时间 | 标注最近一次复核月份 |
| 来源状态 | 官方已核、双源可追溯、待人工复核 |
| 官方来源 | 可点击回到官方文档或权威项目页面 |

## 写作边界

把复杂概念讲简单，不等于把概念讲窄。涉及模型能力、API 行为、价格、限制、参数时，必须按最新官方文档复核后再写入卡片。

## 分类架构

当前固定八类：AI 基础认知、主流大模型体系、AIGC 应用细分、AI 配套技术、前端 & 网页搭建、数据 & 存储、AI 行业 & 场景应用、进阶常识。
