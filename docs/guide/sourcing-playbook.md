# 搜索录入

## 搜索渠道

### 权威精准

优先用官方文档、技术博客、开源项目文档、机构课程、白皮书和行业报告。适合核对定义、版本、参数、限制和主流产品信息。

常用搜索式：

| 目的 | 搜索公式 |
| --- | --- |
| 官方定义 | 产品名词 + 官方文档 |
| 概念说明 | 名词 + 介绍 |
| 行业趋势 | 人工智能行业白皮书 |
| 生成式 AI 趋势 | 生成式 AI 发展报告 |

### 小白科普

用于改写成人话，不能直接当权威来源。可参考知乎、掘金、稀土、InfoQ、少数派、爱范儿、B 站、百度百科、维基百科、菜鸟教程。

### 查漏补缺

专项搜索命令行、框架、数据库和 AIGC 细分主题。

| 类目 | 搜索公式 |
| --- | --- |
| 命令行 | ffmpeg 常用命令 教程 |
| 代码管理 | git 入门指令 |
| 依赖 | npm 依赖大全 |
| 前端 | Vue 基础概念 |
| 数据库 | Redis 作用 通俗讲解 |
| AIGC | 提示词工程 基础 |
| AI 风险 | AI 幻觉 是什么 |

## 关键词公式

| 公式 | 用途 |
| --- | --- |
| 名词 + 通俗解释 | 拿大白话文案 |
| 名词 + 是什么 + 作用 | 得到定义和用途 |
| 名词 + 入门教程 | 补实操和案例 |
| 名词1 + 名词2 + 区别 | 做对比类卡片 |
| AI + 类目 + 知识点汇总 | 批量收集整类内容 |

## 录入规则

1. 同一个名词至少看 1 个官方来源，再用 2 篇正规科普辅助理解。
2. 删除营销话术和夸张结论，只保留定义、作用、用法和边界。
3. 命令、工具、依赖类内容能测试就先测试，再写入卡片。
4. 单张卡片只讲一个主概念，重复概念做引用，不新建重复卡。
5. 卡片按固定结构写：标题、配图、一句话解释、核心作用、简单例子、官方来源、注意事项。

## 扩充节奏

先填满一级大类，再细化二级知识点，最后补行业应用和前沿新名词。模型、工具出新版本时，新增卡片或标注新版变化；淘汰内容标注已下线或旧版。
